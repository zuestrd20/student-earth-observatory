# 地球觀察室｜學生互動地球

繁體中文教育用互動地球，使用真正的 Three.js WebGL 2 三維球體。人口、人口密度、GDP總量及人均GDP以WDI 2023為主，缺值另以Wikipedia核實補充並標示實際年份；218個國家與地區可搜尋，最多比較4個。

## 直接使用

解壓後雙擊 `earth-observatory-offline.html`。Three.js、地圖、資料、樣式皆內嵌，無需網路及npm。查閱外部來源連結才需要連線。瀏覽器需支援WebGL 2才能顯示3D；不支援時會明確顯示「資料探索模式」，搜尋、數值卡、比較板仍可使用。

需要一般網站版本時，`dist/` 是完整靜態站；用本機靜態伺服器開啟 `dist/index.html`。不可直接用file方式開啟dist，因瀏覽器會限制模組與fetch；請改用上述單檔HTML。

## 操作

- 拖曳旋轉，滾輪或雙指縮放；點選國家看資料。觸控與OrbitControls原生操作。
- 地球取得鍵盤焦點後，方向鍵轉動、＋／−縮放。介面有放大、縮小、重設視角與自轉開關。
- 搜尋中文、英文或ISO3代碼；台灣／臺灣皆可。地圖省略的小國亦可搜尋。
- 國家名稱在滑鼠指向時顯示；全部名稱列於可鍵盤操作的搜尋清單，避免地球上同時218個標籤重疊。
- 切換四種指標；加入最多4個地方。瀏覽器上一頁／下一頁恢復國家、指標與比較板。
- 「重設視角」只重置地球，不清除比較；「清空比較」只清除比較板。

## 正確解讀

地球採六級固定數值範圍，每一指標有自己的單位與級距。人口分界為100萬、1000萬、5000萬、1億、10億；俄羅斯約1.4億為亮橙色第5級，10億以上為红色第6級。範圍含下限、不含上限。選中級距與hover精確值提供文字輔助，不以顏色單獨傳達資訊。球面使用不受照明影響的sRGB材質，確保與圖例一致。比較長條為線性比例。

null／無資料不當作0，不納入尺度或比例。人口密度為每平方公里陸地面積。GDP是現價美元，非PPP；人均GDP是平均產出，不是收入或薪資，也不呈現所得分配。

原32個缺值已補27項；台灣人口採Wikipedia 2020普查，GDP與人均為2023，明示來源與年份。另保留2023年底戶籍人口23,420,442人的獨立官方卡。不同年份不可當同年排名。台灣、海峽群島及科索沃陸地密度，以及直布羅陀GDP兩項仍缺；科索沃總面積密度146僅列附註，不混進陸地密度尺度。詳細見WIKIPEDIA_SOURCES.md。

## 開發與重建

Node.js 22.12+（本次24.19.0）。版本固定於package.json及package-lock.json。

    npm ci
    npm run build
    node scripts/offline.mjs
    npm test

開發預覽 `npm run dev`。產出不包含node_modules。Three.js 0.180.0、d3-geo 3.1.1、Vite 7.3.6。無執行時CDN、無追蹤器、無使用者資料傳出。

## 驗收狀態

已通過資料、球面坐標正反轉、已知國家polygon picking及離線DOM互動測試；npm正式build成功，依賴audit為0項已知漏洞。測試詳見 `VALIDATION.md`。

**尚未完成真正GPU／WebGL 2裝置的畫面與拖曳驗收。** 2026-10-04公開後，雲端瀏覽器與正常啟動的原生Chromium均回報WebGL 2不可用，實際顯示資料探索模式。未修改GPU或安全設定，也未使用假3D画面冒充驗證。無WebGL分支已通過兩個瀏覽器畫面檢查，搜尋／四國比較／切換／Back／移除與清空已通過公開頁真實操作；這不等於3D渲染驗收。請在正常支援WebGL 2的裝置開啟離線版後，依VALIDATION中的清單確認。
